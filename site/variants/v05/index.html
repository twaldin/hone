01

One kernel, three uses

There is no separate “meta” system. The same durable coding-session kernel that improves a JSON parser is the one that improves the process that improves it. What changes between uses is the target — never the discipline around it.

1a — ARTIFACTS

Optimize artifacts

Point Hone at a concrete objective — build time, binary size, throughput, conformance-preserving refactors. Runs are resumable and every intermediate state is persisted locally; a crash or a week away loses nothing.

1b — TASK-BUILDERS

Optimize task-builders

The programs that construct optimization tasks are themselves artifacts. Hone tunes them against held-out evaluation, so the tasks it later attempts are better-posed than the ones it started with.

1c — THE OPTIMIZER

Optimize the optimizer

Bounded recursive self-optimization: the controller searches for improved versions of itself, with recursion depth capped, budgets reserved up front, and every promotion contingent on independent evaluation and a human gate.

02

How the campaign works

The flagship experiment asks a falsifiable question: can a coding agent find a measurably better version of itself, twice in a row, on work it has never seen? Every step is designed so that the answer — either answer — is trustworthy.

STEP 1

Capsules — the unit of evidence

A capsule is a frozen, sandboxed build-or-optimization benchmark: a pinned source tree, a deterministic harness, and a protected scoring oracle. The panel spans real OSS workloads — JSON parsers, allocators, codecs, bundlers, resolvers — alongside owner-authored coding tasks. Once admitted, a capsule does not change for the life of the campaign.

STEP 2

Stage A — develop G1 HUMAN GATE

The starting controller G0 runs the inner optimization loop across a frozen panel of development capsules, proposing candidate controllers. The best-supported candidate is selected as G1 — subject to independent evaluation and a mandatory human approval gate before promotion.

STEP 3

Stage B — paired tournament, G2 HUMAN GATE

On a fresh panel, G0 and G1 attempt identical work in paired runs — same capsules, same budgets, same seeds where the harness permits. The pairing isolates the controller as the only variable. The stage yields G2, again behind a human gate.

STEP 4

Terminal — the untouched holdout

G0, G1, and G2 are compared on terminal holdout capsules that no controller, prompt, or selection decision ever saw during development. This is the pre-registered estimand: adjacent-generation transfer measured on work the campaign could not have overfit.

03

RelayBench — results, either way

RelayBench is the reporting system for the recursive campaign. Its thresholds were registered before the first run; when the campaign concludes, it publishes the outcome as success or failure against those thresholds. No results are published yet; every slot below is a labeled placeholder.

04

Architecture of distrust

A self-improving optimizer is the last system whose scores should be taken on faith. Hone assumes its own agent will game the score if it can, and measures accordingly: the trusted runtime stays small and frozen, and everything the agent can mutate is scored from outside the walls.

SANDBOX ISOLATION

  • networknone — no egress from any evaluation
  • rootfsread-only; writable scratch only where declared
  • capabilitiesdropped to the floor
  • lifecyclea fresh container for every evaluation
  • containersmutation and evaluation run in separated images

GAMING RESISTANCE

  • timingmeasured by a trusted parent process, never self-reported
  • binariessealed measurement tooling the agent cannot rewrite
  • oraclesscoring logic protected from the code under test
  • panelscorpus and holdouts frozen before search begins

INDEPENDENT REVIEW

  • red-teamcapsules and results reviewed by parties incentivized to find the seam
  • successorscandidate controllers evaluated independently of the loop that proposed them
  • replayruns persisted and replayable end to end

HUMAN GATES

  • G1 gateno Stage-A promotion without explicit human approval
  • G2 gateno Stage-B promotion without explicit human approval
  • depthrecursion bounded; budgets reserved for ancestors up front
  • secretsstrict source and credential isolation from the agent
If the result is real, it survives all of this. If it isn’t, RelayBench says so — in the same report, at the same thresholds.
