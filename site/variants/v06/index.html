LEVEL 01

ONE KERNEL, THREE USES

There is no separate “meta” system. The same durable coding-session kernel that improves a JSON parser is the one that improves the process that improves it. What changes between uses is the target — never the discipline around it.

1A

OPTIMIZE ARTIFACTS

Point Hone at a concrete objective — build time, binary size, throughput, conformance-preserving refactors. Runs are resumable and every intermediate state is persisted locally; a crash or a week away loses nothing.

1B

OPTIMIZE TASK-BUILDERS

The programs that construct optimization tasks are themselves artifacts. Hone tunes them against held-out evaluation, so the tasks it later attempts are better-posed than the ones it started with.

1C

OPTIMIZE THE OPTIMIZER

Bounded recursive self-optimization: the controller searches for improved versions of itself, with recursion depth capped, budgets reserved up front, and every promotion behind independent evaluation and a human gate.

LEVEL 02

THE CAMPAIGN — WORLD MAP

The flagship experiment asks a falsifiable question: can a coding agent find a measurably better version of itself, twice in a row, on work it has never seen? Every stage is designed so that the answer — either answer — is trustworthy.

1-1 · CAPSULES

THE UNIT OF EVIDENCE

Frozen, sandboxed benchmarks: pinned source tree, deterministic harness, protected scoring oracle. Real OSS workloads plus owner-authored tasks. Once admitted, a capsule never changes.

▲ HUMAN GATE 1-2 · STAGE A

DEVELOP G1

G0 runs the inner loop across a frozen development panel, proposing candidate controllers. The best-supported candidate becomes G1 — after independent evaluation and explicit human approval.

▲ HUMAN GATE 1-3 · STAGE B

PAIRED TOURNAMENT → G2

On a fresh panel, G0 and G1 attempt identical work in paired runs — same capsules, budgets, seeds where the harness permits. The pairing isolates the controller as the only variable.

1-4 · TERMINAL

THE UNTOUCHED HOLDOUT

G0, G1, G2 compared on holdout capsules no controller, prompt, or selection decision ever saw. Adjacent-generation transfer, measured on work the campaign could not have overfit.

LEVEL 04

RULES OF PLAY — ARCHITECTURE OF DISTRUST

A self-improving optimizer is the last system whose scores should be taken on faith. Hone assumes its own agent will game the score if it can, and measures accordingly: the trusted runtime stays small and frozen, and everything the agent can mutate is scored from outside the walls.

SANDBOX ISOLATION

  • networknone — no egress from any evaluation
  • rootfsread-only; writable scratch only where declared
  • capabilitiesdropped to the floor
  • lifecyclea fresh container for every evaluation

GAMING RESISTANCE

  • timingmeasured by a trusted parent process, never self-reported
  • binariessealed measurement tooling the agent cannot rewrite
  • oraclesscoring logic protected from the code under test
  • panelscorpus and holdouts frozen before search begins

INDEPENDENT REVIEW

  • red-teamcapsules and results reviewed by parties paid to find the seam
  • successorscandidates evaluated independently of the loop that proposed them
  • replayruns persisted and replayable end to end

HUMAN GATES

  • G1 gateno Stage-A promotion without explicit human approval
  • G2 gateno Stage-B promotion without explicit human approval
  • depthrecursion bounded; budgets reserved up front
  • secretsstrict source and credential isolation from the agent
