01 / KERNELNO SEPARATE META SYSTEM

One kernel.
Three levels of leverage.

1a

Artifacts

Build time. Binary size. Throughput. Conformance-preserving refactors. Every intermediate state persisted locally — a crash or a week away loses nothing.

1b

Task-builders

The programs that pose optimization tasks are artifacts too. Hone tunes them against held-out evaluation, so tomorrow's tasks are better-posed than today's.

1c

The optimizer

Bounded recursion. Depth capped. Budgets reserved up front. Every promotion behind independent evaluation and a human gate.

02 / METHODFALSIFIABLE BY DESIGN

CAN IT BEAT ITSELF — TWICE?

On work it has never seen. That is the flagship question, and every step of the campaign is built so that either answer is trustworthy.

FREEZE

Capsules

STAGE B · HUMAN GATE

03 / TRUSTSCORED FROM OUTSIDE THE WALLS

Built on the assumption
that scores lie.

Net: noneNo egress from any evaluation. Read-only rootfs. A fresh container every time. Mutation and evaluation never share an image.
Trusted clockTiming measured by a trusted parent process — never self-reported. Sealed measurement tooling the agent cannot rewrite.
Frozen panelsCorpus and holdouts fixed before search begins. Scoring oracles protected from the code under test.
Hostile reviewCapsules and results examined by parties incentivized to find the seam. Successors judged independently of the loop that proposed them.
Human gatesNo promotion at G1 or G2 without explicit approval. Recursion bounded, ancestor budgets reserved first, secrets isolated.
