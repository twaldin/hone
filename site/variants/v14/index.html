01

One kernel, three targets

SAME DISCIPLINE AT EVERY LEVEL
TARGET/1a

Artifacts

Build time, binary size, throughput, conformance-preserving refactors. Runs are resumable; every intermediate state persists locally.

TARGET/1b

Task-builders

The programs that construct optimization tasks are artifacts too — tuned against held-out evaluation so later tasks are better-posed.

TARGET/1c

The optimizer itself

Bounded recursion: depth capped, budgets reserved for ancestors up front, every promotion behind independent evaluation and a human gate.

02

The campaign, as a run log

FALSIFIABLE · PRE-REGISTERED
RECURSIVE CAMPAIGN · EVENT STREAMORDER IS THE PROTOCOL
  1. T+00ADMIT Capsules frozen. Pinned OSS + owner tasks, deterministic harnesses, protected scoring oracles. Once admitted, never changed. FROZEN
  2. T+01SEAL Sandbox up. Network none, read-only rootfs, fresh container per evaluation, mutation and evaluation in separated images. NET:NONE
  3. T+02STAGE A G0 searches for G1 across the development panel. The best-supported candidate is promoted only after independent evaluation. HUMAN GATE
  4. T+03STAGE B Paired tournament, G0 vs G1 on a fresh panel — identical capsules, budgets, seeds. The controller is the only variable. Yields G2. HUMAN GATE
  5. T+04TERMINAL G0 · G1 · G2 on untouched holdout capsules nothing ever saw during development. The pre-registered estimand. HOLDOUT
  6. T+05REPORT RelayBench publishes success or failure against thresholds registered before the first run. Goalposts do not move. EITHER WAY
