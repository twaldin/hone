Platform

One kernel. Three levels of leverage.

There is no separate “meta” system. The same durable kernel that improves a JSON parser improves the process that improves it — the discipline around it never changes.

Optimize artifacts

Point Hone at a concrete objective — build time, binary size, throughput, conformance-preserving refactors. Every intermediate state persists locally.

Optimize task-builders

The programs that construct optimization tasks are artifacts too. Hone tunes them against held-out evaluation so future tasks are better-posed.

Optimize the optimizer

Bounded recursive self-optimization: recursion depth capped, budgets reserved up front, every promotion behind independent evaluation and a human gate.

Sealed measurement

Timing comes from a trusted parent process, never self-reported. Scoring oracles stay outside the walls the agent can touch.

Hardened sandbox

Network none, read-only rootfs, capabilities dropped to the floor, a fresh container per evaluation. Mutation and evaluation never share an image.

Durable by default

Runs are resumable and replayable end to end. A crash — or a week away — loses nothing. Local SQLite, no cloud dependency.

Method

A falsifiable campaign, gated by humans

Can a coding agent find a measurably better version of itself — twice in a row — on work it has never seen? Every step is designed so either answer is trustworthy.

Capsules

Frozen, sandboxed benchmarks: pinned source, deterministic harness, protected scoring oracle. Admitted once, never changed.

Sandbox

The trust boundary. No egress, read-only root, separated mutation and evaluation containers.

Stage A → G1

The starting controller G0 searches a frozen development panel for a better controller, G1.

Stage B → G2

Paired G0-vs-G1 tournament on a fresh panel — same capsules, budgets, seeds. Yields G2.

Terminal holdout

G0, G1, G2 compared on untouched capsules no controller ever saw. The pre-registered estimand.

Trust architecture

Built on the assumption that scores lie

A self-improving optimizer is the last system whose numbers should be taken on faith. The trusted runtime stays small and frozen; everything the agent can mutate is scored from outside the walls.

Sandbox isolation

  • networknone — no egress from any evaluation
  • rootfsread-only; writable scratch only where declared
  • lifecyclea fresh container for every evaluation
  • containersmutation and evaluation run in separated images

Gaming resistance

  • timingmeasured by a trusted parent process, never self-reported
  • binariessealed measurement tooling the agent cannot rewrite
  • oraclesscoring logic protected from the code under test
  • panelscorpus and holdouts frozen before search begins

Independent review

  • reviewerscapsules and results examined by parties incentivized to find the seam
  • successorscandidates evaluated independently of the loop that proposed them
  • replayruns persisted and replayable end to end

Human gates

  • G1 gateno Stage-A promotion without explicit human approval
  • G2 gateno Stage-B promotion without explicit human approval
  • depthrecursion bounded; budgets reserved for ancestors up front
  • secretsstrict source and credential isolation from the agent
